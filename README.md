# دَفتَرچه

 ساخته‌شده برای استفادهٔ خودم

## ویژگی‌ها
- تسک‌ها با اولویت، دسته‌بندی و مهلت
- تایمر تمرکز (پومودورو) با زمان قابل شخصی‌سازی
- استریک روزهای پیاپی + نمودار هفتگی + ثبت مود روزانه
- قورباغهٔ روز (مهم‌ترین کار ناتمام)
- تاسِ شانس برای انتخاب کار بعدی
- تم روشن/تاریک، جستجو، درگ‌ودراپ، ذخیره در مرورگر
