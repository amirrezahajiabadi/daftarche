# دَفتَرچه

دفترچه‌ای برای اینکه بفهمی **الان چه کاری ارزش انجام دادن دارد** — یک اپ وب آفلاین‌پذیر و بدون حساب کاربری برای کارهای روزانه، تمرکز و خواندن. داده‌ات روی دستگاه خودت می‌ماند.

**دمو:** <https://amirrezahajiabadi.github.io/daftarche/>

## چه می‌تواند
امروز و پیشنهاد «الان چی کار کنیم؟» · کارها با اولویت، مهلت و یادآور · تقویم هفتگی با درگ · تایمر تمرکز و سابقه · کتابخانه و خوانندهٔ PDF (هایلایت، قلم، یادداشت) · آمار، استریک با مرخصی، ۲۹ نشان، کارت آمار برای اشتراک · هشت تم · پشتیبان‌گیری JSON.

## اجرا
اپ ماژول ES و Service Worker دارد، پس `file://` کار نمی‌کند؛ یک سرور استاتیک کافی است:

```bash
python -m http.server 8000
# http://127.0.0.1:8000/
```

## تست
بدون نصب چیزی، فقط با Node (۲۰ به بالا):

```bash
npm test
```

## فناوری
JavaScript خالص و ماژولار، بدون فریم‌ورک و بدون build. داده در `localStorage` (و PDFها در IndexedDB)، با لایهٔ ذخیره‌سازی محافظت‌شده (`js/store.js`) و پشتیبان JSON (`js/backup.js`). Content-Security-Policy از طریق `<meta>` در `index.html`.

## انتشار
نسخه فقط در `js/version.js` نوشته می‌شود. هر تغییر در فایل‌های پوسته → `BUILD` جلو برود؛ هر انتشار → `RELEASE`، ورودی در `js/changelog.js` و بخش تازه در `CHANGELOG.md`. فایل تازه در `css/` یا `js/` را به `SHELL` در `sw.js` اضافه کن. جزئیات: [`AGENTS.md`](AGENTS.md).
